## 风险与未验收项

- 东京在 Server 镜像切换的 03:46:48 UTC 发生一次 502，随后心跳与 9443 TCP 恢复；启动阶段能力发现遇到一个 starting 实例。最终服务端元数据读取显示 Claude running，Codex/DSH 仍 starting；没有把进程在线当作全部 Runtime 任务可用的证明，也没有强制重置配置或发任务探测。这些实例的后续任务能力需要用户在设备页验收。
- instabox2 依据用户执行回执记录，没有远程独立复测；Windows/Intel Mac 下载安装及真实登录、用量、限额上下文延续仍需用户验收。
- 被动 Claude 用量可能无事件/字段或过期；终端独立启动的 Claude 不会被 Fork 捕获。旧缓存不会伪造为刚更新，原生账号登录和账号额度依旧独立于客户端升级。
- 原有模型渠道由 Server 接收 Key 的既有风险未在本次改动；没有扩展该路径或读取实际厂商凭据。
