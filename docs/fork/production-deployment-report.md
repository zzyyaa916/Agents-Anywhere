## 停用与风险

在服务器 root 终端执行：

```sh
bash /opt/agents-anywhere-fork/disable-fork.sh
```

仅停用改动版并移走它的独立 Nginx 配置，保留数据库和附件；官方版继续使用原网址。默认不删除卷，不运行全局清理命令。

同机隔离仍共享宿主资源与 IP 的 TLS 证书；不能覆盖宿主机或整块磁盘故障。证书继续使用官方既有续期机制。改动版数据不会自动同步回官方版；真实用量与续聊仍需独立用户/虚拟机中的配套分叉 Connector 验收，未接管现有官方 Connector。Windows/macOS 安装包后续已通过原生构建生成，见[安装包交付记录](native-installer-delivery.md)。本轮不重复此前产品代码的全部测试。
