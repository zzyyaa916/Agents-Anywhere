# 会话选择固定规则

用户在新建会话时选择「Fable 5.2＋低思考强度」，该组合属于这个会话，后续回合和 Connector 重启后继续使用。用户主动切换且 Runtime 接受成功后才更新；失败不覆盖原值，但会阻止后续发送，直到用户重新明确选择。此规则通过共享的 RuntimeInstance 层应用于 Claude、Codex、DSH 等实例。

## 实现与作用范围

模型和思考强度使用目录中同一个完整 model selection ID 保存，不拆开推测默认强度。SessionSelectionStore 使用已有的实例同步状态存储，按 Runtime 实例、来源及会话隔离；不改变接口或数据库结构。持久化的键包含会话标识，可随现有原生历史删除流程清理。

- 对支持模型目录的 Runtime，创建时必须明确选择模型；若模型支持思考强度，还必须选定对应强度。缺失时在调用原生创建前拒绝，绝不使用默认模型。创建成功后保存传入的明确选择；创建失败不保存错误值。
- 后续回合读取保存值并下发 Runtime，优先于 Server 转发的旧状态快照。回合请求不是主动切换入口，不能更新保存值。
- 主动切换使用既有 session.selections.update 接口，部分更新合并其他保存项；模型切换期间标记为需要确认，成功后写入并解除阻止，失败保留原值但继续阻止发送；只改权限不会解除模型确认要求。
- 会话状态读取、普通状态事件和 DSH 批量状态事件补回缺失项；原生默认值不能覆盖已选模型及思考强度。规划模式等临时权限状态可以正常显示，但不会改写保存的用户权限选择。
- 选项无效或已不再受 Runtime 支持时，沿用原有校验明确报错，不静默选择其他模型。

## 未知及旧会话

未明确选择过的原生导入会话继续保留未知状态，并在调用原生回合前拒绝发送，要求先选择模型及强度。模型目录支持的 Runtime 不再允许通过选择「运行时默认」、传空值或旧 Server 快照绕过此要求；没有模型目录能力的 Runtime 不受此要求影响。

此前已经丢失、且无可靠记录可恢复的选择不能凭空补回；这类旧会话需要重新明确选择一次。升级后成功创建或切换的选择将保存下来。

当前后台任务仍由各 Runtime 自身恢复；本规则不改写原生历史、配置文件或其他会话，也不通过额外模型请求猜测实际配置。

## 验证

新增测试覆盖三种 Runtime 的选择恢复、成功与失败切换、部分更新、旧 Server 快照、未知会话、显式默认、实例隔离、DSH 批量通知及真实实例同步存储的落盘重建。与 Supervisor、实例包装、存储、状态缓存及历史清理相关回归及新增的禁止默认模型测试共 98 项通过。未调用真实模型，也未部署到线上。

## 切换即时反馈

Web、Desktop 和 Android 使用运行时确认结果显示通知，包含选定模型及思考强度（或权限名称）。仅点击或乐观更新不会触发成功提示；返回选择与请求相符才确认；明确在 pendingSelectionScopes 中的变更提示「下一轮生效」。回包丢失或结果不一致时，客户端自动读取一次当前状态核查，用户无需手动刷新；仍未确认则提示重新选择。多次快速切换时，Web/Desktop 仅通知最后一次变更的结果。

模型确认标签、未确认及延后生效的判定已有 Web/Desktop 回归测试；安卓已接入现有 Toast，但本环境缺少 JDK，尚未编译或真机验证。

通知补充验证：Web/Desktop 的 selection-confirmation.test.mjs 均通过，确认辅助函数的严格 TypeScript 检查通过，两个 SessionDetail 组件语法转译通过，翻译 JSON 与 Android XML 解析通过；尚未做完整前端构建或安卓真机验证。安卓发送选择更新改为只提交本次变更的 scope，避免权限变更被误识别为模型切换。
