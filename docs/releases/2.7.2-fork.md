# Fork 2.7.2 修复批次

基线为 `fix/con+be/upgrade-2.7.1` 的 `346accde`，包含 PR #1–#19。2.7.2 只做修复和小范围可靠性改动，没有新增数据库迁移。

## 主要修复

- 时间线增量写入增加下限护栏，连接器重启后的小序号不再插入历史前部；平台限额条目改为追加。
- 限额恢复容忍未激活窗口的 `resetsAt=null`；探针整窗缺失、凭据锁超时和字段异常都有独立告警/计数。
- Claude 审批重复点击返回“已处理”，不再抛出 `not waiting`；审批后的协议更新推送失败保留调试日志。
- 用量采集对连接器回传的重试时间设置上限，超前 `fetchedAt` 记为失败；观察器创建失败会重试并留痕。
- 删除项目/会话时，数据库记录先提交，附件清理由审计行在事务外驱动；设备清理预检超时单独放宽到 300 秒，失败会取消预检回执；同账号其他 Connector 的嵌套路径纳入保护。
- Codex 即时补充按 `clientMessageId` 去重；运行中补充拒绝空内容，并检查归档/限额状态，只有成功才记用量。
- 未配置 Claude 探针时，Codex 用量仍可手动刷新；用量面板显示 Codex 错误、解析告警，未激活窗口不显示重置时间。
- Connector KV 增加跨进程文件锁；Claude 失败消息的异常文本也脱敏；`.md` 等普通文件上传路径补回归。
