# Fork 2.6.0 Web 测试版

新增 1～3 个 AI 自选（含 2 个）、同基线 worktree、独立实时聊天分屏、结果与 diff 对比，以及带自定义指令的跨 AI 快照转发。复用普通项目、会话、消息、Runtime 与审批机制，没有新增调度引擎或依赖包。

先在 Web 测试，再交付桌面与 Android 新入口；客户端包发布时继续使用应用内检查、下载、完整性校验与系统安装确认，不要求用户逐次前往 GitHub 下载。源码统一标记 2.6.0 表示新增 API 配套，尚不代表安装包已经发布。2.5.7 客户端可继续使用原功能。iOS 只同步版本标识，不提供本功能。

## 配套与迁移

- Server、Web、Connector 需要本次 2.6.0 配套代码；数据库从 v2_56 升到 v2_57，只新增 task_groups 表及索引，不修改旧会话内容。
- 端点与约束见 [任务组 API](../api/task-groups.md)。旧 Connector 不识别 worktree RPC 时，准备操作明确失败，不调用 agent。
- 每个候选注册为普通项目/会话，保留原项目的严格工作目录绑定。来源项目必须是 Git 仓库根目录，首次准备前先提交或自行保存改动。
- 首版使用运行中 agent 的默认模型与权限，不复制账号、凭据、忽略文件和依赖；仅在同一设备内运行和交接，候选共享账号额度。

## 使用与验收

1. 打开新会话页「选择 AI 做任务（测试）」，选择项目与 1～3 个 AI，像聊天一样填写想做的事，不要求单独填写验收标准。
2. 点击「下一步：确认任务」，再点击「开始执行」；准备阶段不发送模型任务。
3. 会话创建后自动分屏，每栏使用自己的会话 ID，复用原有实时聊天、消息队列、审批、附件与停止操作；右上角可收起、展开或关闭，关闭只隐藏窗口，不取消任务，之后可重新打开。
4. AI 停止并有回复后，每栏右上角的「转发给其他 AI」可选择接收者、预览结论并填写指令；点击「转发并发送」后才启动接收者的新会话，保留所有原聊天栏。转发指令优先于原审查/继续默认提示。

超时或服务重启后的派发不自动重试，先查原会话。交接通过私有 Git index 捕获已有提交、未提交、新增和二进制文件，不改来源 index/HEAD；忽略文件不会带过去。快照上限 64 MiB、展示 diff 上限 512 KiB，超限明确报错。

worktree 隔离检出文件，不是进程/网络沙箱。审查使用明确的只审查指令及独立副本，不承诺强制只读。原生线程与隐藏上下文不会跨厂商迁移；交接包含原需求、来源标识、基线/快照和最近会话记录（可能截断），测试结果以原会话证据为准。首版不自动合并、回收 worktree 或为限额任务自动重发。

## 当前验证边界

真实 Git 仓库测试覆盖三候选同基线与互不影响、并发准备幂等、脏目录与路径/链接拒绝、新增/二进制/删除文件交接、来源 index/HEAD 保留和 diff 超限。后端测试覆盖按用户鉴权、准备不派发、并发领取一次、超时/重启不重发、运行中拒绝交接及固定快照接力。浏览器组件测试覆盖准备、显式启动三份、查看结果、选择、预览交接和再次确认启动。

测试使用临时仓库、独立测试数据库及模拟 Runtime，未调用用户付费模型。上线与真实 Codex/Claude 任务验证仍需单独记录，不将单元测试当作已经上线或真机验收。
