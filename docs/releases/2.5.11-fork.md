# Fork 2.5.11 Windows 标题栏修复

修复 2.5.10 在 Windows 原生桌面标题栏没有显示「转发给其他 AI」的问题。先前只在普通页面标题栏挂载了入口，桌面通过 portal 使用另一分支，因此更新远程 Connector 不能解决按钮缺失。本次在原生桌面标题栏挂载同一转发控件，并新增两种标题栏的实际渲染与点击测试。

Windows 安装包版本为 2.5.11，配套服务端版本仍为 2.6.0；服务设置页显示的是服务端版本，桌面「检查更新」对话框中的当前版本及 EXE 属性显示的是安装版本。

本版只修复桌面入口，沿用 2.5.10 的 Server/Web/Connector 更新包，无需重复更新已成功升级的 Server。Oracle、instabox2 等远程工作设备仍需执行配套 Connector 更新；否则新接口执行时可能失败。新会话发送消息进入会话后可从右上角打开转发；来源 AI 运行时转发按钮禁用。

安装包未签名，作为可手动下载的预览版发布；尚未执行原生 Windows 实机安装或真实付费 AI 回合。保留原稳定发布及应用内更新逻辑。
