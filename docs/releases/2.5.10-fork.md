# Fork 2.5.10 Windows 预览安装包

本安装包包含 c8c97852 的最新单 AI、多 AI 转发修复：会话右上角可选择 1～3 个 AI，分别配置模型、思考强度和权限，转发原始任务、近期对话、历史及新增附件和可用代码快照，目标会话保留在原项目。部分失败后重试复用操作标识，已投递任务不会自动重复执行。

## 下载与安装

- 文件：`Agents.Anywhere.Fork.Setup.2.5.10.exe`，Windows x64 NSIS 安装包。
- 等待本机 Fork 任务结束，退出 Fork 后覆盖安装原 Fork 目录，不覆盖官方版。
- 本包未签名，Windows 可能显示未知发布者提示；尚未在原生 Windows 实机完成安装验收。
- 本次仅提供 Windows 包，不含 Android 或 Mac 安装包。

## 配套要求

新增单会话转发需要部署本分支的 Server（新增 `/api/v2/task-groups/from-session/{sessionId}/handoffs`）以及工作设备 Connector（新增 `worktree.adopt`）。本包已携带最新本机 Connector；远程设备的 Connector 不会随桌面覆盖安装而自动升级。

当前线上 Server/Web 尚未部署本次修复，原版本号 2.6.0 不能单独证明已包含新接口。仅安装客户端时原有功能保留，新增转发需等待服务端和相应工作设备配套更新。无数据库迁移。

因此本次作为 GitHub 预览版发布，可手动下载安装；稳定版应用内更新继续使用既有正式 Release，不把尚未完成服务端部署的功能自动推送给用户。
