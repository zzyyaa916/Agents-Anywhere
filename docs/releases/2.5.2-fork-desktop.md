# 2.5.2 分叉桌面版双 Connector

Desktop / renderer / Connector / Web 源码为 2.5.2，兼容已部署的 Fork Server 2.5.1，无数据库迁移。Windows x64 与 macOS universal 沿用 Fork 安装身份，可更新已安装的 2.5.1 Fork；勿选官方版安装目录。

## 登录和使用

1. 保持官方版运行，启动新版 Fork，等待本机 Connector 准备完成。
2. Windows 右键 Fork 托盘图标，macOS 从应用菜单选择「登录独立 Codex 账号」及「登录独立 Claude Code 账号」，在新终端中完成厂商原生登录。也可从设置「打开数据目录」双击相应 Login 文件。登录输出不进入 AA 日志，不要分享原生登录码。
3. 在 Fork 的本机设备中添加并启用 Codex / Claude Code Agent。仅登录原生工具或登记设备不会建立用量采集来源，无需先发起任务。
4. 点用量圆圈查看；刷新继续受采集间隔和退避限制，失败显示不可用，不生成测试额度。Web 与桌面读取同一 Server 的脱敏快照。
5. 两版各发起一个测试任务，确认分别在各自设备和会话中执行。相同项目文件仍可能被两个任务同时修改，测试时请选择两个不同的空目录。

## 隔离与升级限制

原生账号在 `~/.agents-anywhere-fork/native/`，官方原生目录不复制、不迁移，Fork 重新登录。同一个厂商账号的额度并不会翻倍。Codex Desktop IPC 接管在 Fork 关闭，自定义 Codex Home 只能指向 Fork 自己目录；原有指向官方目录的配置需清空该字段再保存。

旧 AA 会话记录保留，但旧会话引用的官方原生历史不会复制到新目录，不能承诺它们在新隔离账号中恢复；请新建测试会话。2.5.2 新隔离目录内的会话继续沿用既有续聊机制。

关闭或卸载 Fork 后可继续使用官方版；本轮不修改官方服务、网络或其他服务器，不执行已暂停的迁移。Mac 安装包未公证，Windows 安装包未签名。
