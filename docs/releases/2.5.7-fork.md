# Fork 2.5.7 手动应用内更新

按维护者要求，移除桌面与 Android 的自动检查：不在登录、进入前台、打开设置或使用期间查询发布页，也不主动弹出升级提示。只有用户点击「检查更新」才读取维护者发布的稳定版，并可继续在应用内下载、校验与启动系统安装。

已有 2.5.6 客户端可以从应用内检查并升级至本版，无需去发布页找安装包。系统安装确认仍需用户操作，更新前应结束本机任务。桌面与 Android 沿用原应用身份，Android 版本代码 18、签名不变。服务器、网页与远程 Connector 无需更新。

安装与安全限制沿用 [2.5.6](2.5.6-fork.md)：Windows EXE、Intel Mac PKG、Android APK；保留大小与 SHA256 校验。未进行真机覆盖安装验收。
