# 2.5.1 分叉桌面版并排安装

> 本文记录 2.5.1；双 Connector 同时执行任务请使用 [2.5.2](../releases/2.5.2-fork-desktop.md)，并重新登录隔离原生账号。

Windows x64 与 macOS universal 使用 `Agents Anywhere Fork` 名称和 `dev.agentsanywhere.fork.workbench` 标识。安装时保留默认独立目录，勿选择官方版安装目录；无需虚拟机或第二个系统用户。旧的 2.5.0 测试安装包仍有官方标识，不要覆盖安装。

桌面配置、登录态、受管 Connector 配置与环境存放在 Electron 的 Fork 用户目录；桌面安装记录和引导状态存放在 `~/.agents-anywhere-fork/desktop-state.json`。不会自动迁移官方版登录态。浏览器回调使用 `agents-anywhere-fork-desktop://oauth/callback`，改动版 Server 与 Web 须先升级至 2.5.1；官方客户端回调仍受支持，无数据库迁移。Connector 保持 2.5.0。

本机 Connector 全局互斥仍使用 `~/.agents-anywhere/connector-runtime.json`，只允许一个 Connector 管理本机 Runtime。使用 Fork 前，先结束官方版任务并从托盘退出；返回官方版前，同样退出 Fork。启动 Fork 不强行终止官方版进程，也不修改系统网络设置。同一系统用户的 Codex、Claude Code 原生账号和历史仍由原生工具共享，并非两套沙箱。

回退：退出 Fork，启动官方版并连接原服务器。卸载时只卸载名称带 Fork 的程序。服务器的官方 443 与 Fork 9443、数据库和卷继续分离。

验证：桌面状态隔离、独立 OAuth 严格匹配、原登录回调兼容性、Desktop 与 Web 静态检查和原生 CI 构建。未在用户 Windows/macOS 真机安装验收；安装包未签名，macOS 未公证。

下载地址、逐项验收与文件清单见 [并排安装交付记录](../fork/side-by-side-desktop-delivery.md)。
