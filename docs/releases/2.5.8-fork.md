# Fork 2.5.8 多 AI 协作

安装包按维护者指定使用 2.5.8（Android versionCode 20），Server、Web、Connector 保留既有 2.6.0 API 标识。本次扩展既有任务组的附件参数，不新增数据库迁移；需要配套本次 Server，旧的 2.5.7 客户端原功能继续可用。该 Fork 安装包编号有意独立于 API 测试线，不按编号推断接口兼容性。

桌面同步 Web 的多选输入、独立工作区与分屏。Android 新会话页的「多 AI 工作台」在应用内部使用同一 Web 页面，登录只写入配置服务器的精确 origin，无 JavaScript 原生桥，不通过 URL 传递令牌；支持系统文件选择器，不允许跳转到其他 origin，旧 WebView 不支持启动脚本时明确提示升级。原生单会话保留。

首轮附件通过普通会话创建附件接口交付每个 AI，不拼成文字；转发携带原始附件和最近 100 条时间线中可读的附件，最多 10 个，超限或文件不可读明确失败。对话文本保留末尾约 24000 字符。当前代码通过已有 Git 快照机制包含已提交、未提交、新增及二进制文件，忽略文件不复制。

分屏中输入「转发给 Codex：请审核代码」直接转发，不调用来源 AI 生成摘要或扩大其上下文；仅识别独立的明确转发指令，普通讨论不触发。已选 AI 使用原设置，其他运行中 AI 使用其目录默认设置；需要自选模型及权限时使用转发按钮。名称不存在或重名时提示手动选择。忙碌来源会话的指令先进入原队列，结束后建立快照。

统一输入将文字分别放入每栏已有消息队列，各栏根据自身状态发送；单独输入、暂停、恢复、失败保留和即时补充沿用原逻辑。关闭只隐藏组件，不停止任务及队列。离开工作台后浏览器不继续后台发送，重新进入需确认恢复已有队列。

Windows 使用 EXE、Intel Mac 同时构建 DMG 与应用内更新使用的 PKG，Android 使用原身份及原签名。安装包发布与校验记录如下。
