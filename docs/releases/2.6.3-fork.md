# Agents Anywhere Fork 2.6.3（源码交付）

Connector、Windows/Mac Desktop、Android、iOS、Web、Server 与 DSH Bridge 源码版本为 2.6.3；Android versionCode 为 24，iOS build 为 13。源码交付不代表安装包已构建、签名或线上环境已升级，不创建 GitHub Release、不上传安装包。

## Claude 原生用量缓存

`LocalAccountUsage._claude_cached_usage` 仅返回 resets_at 晚于当前时间的窗口；更新时间使用有效窗口中最新的 observed_at，stale 只按该时间与 300 秒阈值判断。全部窗口已重置时返回 unavailable。保留未重置窗口的原始用量，不修改账号识别、原生事件解析、网络收集或刷新限流，不读取凭据。最新观察时间不表示所有窗口同时刷新，界面文案暂不变。

修复需要在运行 Claude 的工作设备更新 Connector；只更新 Server 或客户端无效。在 Fork 内运行一次 Claude 任务后会产生新的原生观察；在 Fork 外运行 CLI 不会更新这份缓存，已有五分钟收集限流仍保留，可能需要等到下一次允许收集及客户端刷新才看到新值。

## 升级要求

用户要求本轮 Fork 版本使用 2.6.3；新增完整删除接口必须配套更新，不能仅凭同一 2.6 主版本假定旧客户端已支持该功能。使用更新包中的 deploy.py 和升级脚本，支持 2.6.2 来源；Server 需先备份并迁移至 v2_58。保持既有 Fork 数据目录、账号、服务用户和配对。若数据库已从 v2_57 迁移到 v2_58 后验证失败，旧镜像会拒绝新 schema，脚本不会自动切回不兼容镜像或还原数据库；需使用兼容镜像恢复，备份路径会在错误中给出。正式签名及安装包构建由使用方完成。


## 完整删除会话和项目

新增 `DELETE /api/v2/sessions/{id}/contents` 和 `DELETE /api/v2/projects/{id}/contents`。桌面、Web、Android、iOS 项目删除已切换到新接口；旧记录删除接口保留兼容，新客户端连接旧 Server 时返回错误，不会把仅删除记录误报为完整删除。本功能随 Fork 2.6.3 源码交付，部署需核对源码提交。

Server、Connector、DSH Bridge 及客户端必须配套更新到本轮源码；先备份数据库并执行 `python -m alembic upgrade head`，新增 v2_58 的可空清理计划列。Fork 更新脚本已加入迁移。固定身份 Claude 设备还需更新包中的受控 Runtime Broker 和独立清理助手；升级脚本仅允许更新既有 root 所有的受控服务。旧 Broker 不支持清理时会拒绝删除。

删除会话清理服务端记录/附件、设备会话附件和缓存，以及对应 Codex、Claude、DSH 原生历史；不会删除共用的项目工作目录。删除项目连同该项目所有会话及整个项目目录永久删除。其他项目使用的重叠目录、其他会话引用的原生历史、系统目录、最终目录符号链接或确认后被替换的目录会被拒绝。原生账号凭据不删除。DSH 当前只支持 JSONL 后端，须先关闭原生会话以释放写入者；正在被原生进程使用的历史不会强删。

离线预检失败时保留记录；记录提交后清理失败时，持久化清理任务由重连恢复机制重试，清理成功前禁止重用该项目路径。删除不可撤销，请保留界面确认提示。未对线上项目运行破坏性验收，也未打包客户端。接口细节见 [完整删除协议](../api/history-cleanup.md)。


### 审核后修正

Codex 立即补充回显兼容 `userMessage` 与 `steeringUserMessage`，保留会话、轮次、文字匹配约束，通过同一个 clientMessageId 消除三端的临时消息重复显示。客户端发送逻辑不变。

完整删除新增放弃剩余清理的二次确认；旧接口可重试完整删除任务，数据库/程序错误不再误报为设备未清理完成。预检拒绝时取消凭据；成功清理后释放凭据并持久化完成阶段，以支持丢失确认后的恢复。原生 Codex 归档和删除分开处理缺失结果，归档返回缺失也继续真正删除。隔离 CLI 0.166.0 测试确认：第二次 archive 返回 no rollout found，但 delete 仍能成功；未调用模型，也未使用现有原生数据。

iOS 本地化保留原格式，仅新增相关键值。稳定父目录别名按真实路径核对；最终目录符号链接和 junction 仍拒绝。Windows 实机和 iOS 编译尚未验证，不能以 Linux 测试代替。
