# Agents Anywhere Fork 2.6.1

Windows 安装包和客户端实际版本均为 **2.6.1**。服务页新增独立的「客户端版本」字段；服务器版本仍为 2.6.0，是独立的服务端版本，不能用来判断 Windows 安装包版本。

## 文字转发与小按钮

任意来源 AI 均可转发给其他目标，例如：

```text
转发给 Claude Code、DSH：请分别审核当前结果和附件
转发给 Codex、DSH：请继续完成剩余工作
转发给 Codex、Claude Code：请交叉检查方案
```

目标须为当前设备上名称唯一的可用 AI，支持选择 1～3 个不同目标。单会话和多 AI 分屏共用转发流程：保留来源会话，在原项目创建目标会话，携带原始任务、近期对话、历史和新增附件及可用代码快照，不调用来源模型，不继承厂商私有上下文。

单会话右上角显示小转发按钮，Windows 原生标题栏与普通页面标题栏均有入口；点击可分别选择目标 AI、模型、思考强度及权限。来源运行时按钮禁用。

## 联立会话

侧栏打开「联立会话」，选择同项目的两条不同 AI 的已有会话并点击「联立显示」。两栏可分别聊天，底部「联立发布」会按各栏状态发送或进入原消息队列。选择、窗口状态、统一输入草稿及部分投递状态按当前账号和服务保存，切换页面后可恢复。

也可从「恢复多 AI 任务」重新打开已创建的分屏任务。新建多 AI 任务会进入该持久工作区，恢复界面不重新调用模型。保持原有的消息队列恢复规则，结果不确定的任务不会自动重放。

## 配套与验证

本版沿用上一版 Server/Connector 的转发接口；已经成功执行 2.5.10 配套更新的 Server 无需重复迁移数据库。Web 需要使用本版静态资源，另附 Server/Web 更新包。Oracle、instabox2 等远程工作设备仍需上一版的 Connector 工作区更新，Windows 包中已携带配套本机 Connector。

回归覆盖三个 AI 分别作为来源向另外两个转发、附件交付、同项目归属、页面切换恢复、部分投递后重试、账号隔离、原生标题栏按钮和安装版本显示。未执行真实付费模型回合、原生 Windows 实机安装或替用户更新远程 Connector。

Windows 安装包未签名。作为预览版提供手动下载安装，保留原稳定发布和应用内更新逻辑；Mac、Android、iOS 不包含本次新界面。
