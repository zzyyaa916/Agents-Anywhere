# Fork 2.5.6 应用内更新

桌面侧栏账号旁的下载图标现在始终可用：点击检查客户端更新；登录时及每 30 分钟检查已发布的 Fork 稳定版，有更新时弹窗提醒。版本比较使用客户端版本，不受服务端版本影响；更新检查不携带应用令牌。

点击「下载并退出安装」后显示进度，核对发布文件大小与 SHA256，再打开 Windows EXE / Intel Mac PKG 系统安装器，并走正常 Connector 退出清理流程。安装过程由系统确认，用户需先结束本机任务。安装后重新打开应用；不会静默替用户安装，也不会向工作设备推送任意代码。Mac 保留 DMG 初次安装方式，新增 PKG 供应用内升级。

Android 个人设置中的「检查更新」已有下载、进度和系统确认安装功能；本版在进入前台及每 30 分钟自动检查，补充大小与 SHA256 校验。沿用 Fork 包名和原签名，版本代码 17。

更新源固定为当前 Fork 仓库的稳定发布；平台资产缺失、草稿、预发布、下载地址不匹配或没有完整性信息时不自动安装。下载不完整、校验失败不会打开安装器。Windows 未商业签名，Mac 未使用 Developer ID 签名/公证，系统可能要求额外确认。

旧客户端无法从服务端收到它尚未实现的桌面更新代码；桌面需先覆盖升级一次至本版。Android 2.5.5 已可通过个人设置更新，无需另找下载地址。账号、会话及配对目录保持不变，服务器和三个远程 Connector 不需要为本功能重新安装。

DSH 的分层检查只保留适用项目，不再把缺少渠道能力与账号用量来源误认为未验证。
