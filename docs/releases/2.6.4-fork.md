# Agents Anywhere Fork 2.6.4（源码交付）

Connector、Windows/Mac Desktop、Android、iOS、Web、Server 与 DSH Bridge 源码版本统一为 2.6.4；Android versionCode 为 25，iOS build 为 14。本次只上传源码，不构建安装包、不创建 GitHub Release、不部署线上环境。

## Claude 双源手动用量

只有手动点击刷新才在指定甲骨文 ARM Connector 执行 OAuth 探针；没有后台、打开面板或撞限额探测，节点离线不故障转移。令牌仅在本机 Claude 身份下读取和使用，不上报或记录；User-Agent 使用实际安装的 Claude CLI 版本。

Server 按账号和窗口分别保留事件与探针最后有效数据，使用 Server 接收时间选择新数据，显示来源和年龄，不按时间清空。部分更新不覆盖其他窗口，失败不修改缓存。跨进程全局单飞，两次成功至少相隔五分钟；429 优先遵守 Retry-After，否则退避翻倍。第三次 429 熔断到次日 00:00 UTC，成功清零，解除熔断后恢复五分钟间隔且不自动请求。三端显示“今日探针已熔断，明日恢复”并禁用刷新。

当前方案替代此前未部署的自动探针方案；完整规则见 [Claude 手动用量探针](../fork/claude-usage-probe.md)。保留 2.6.3 的立即补充去重、完整删除与原生用量缓存修复，参见 [2.6.3 发布说明](2.6.3-fork.md)。

## 升级要求

Server、Connector、Web / Desktop / Android 需配套更新。先备份数据库，再迁移至 v2_59（包含 v2_58 完整删除清理列及 v2_59 双源缓存和持久化探针控制）。更新脚本支持现有 2.6.3 来源，不回滚到不兼容新 schema 的旧镜像。

所有节点默认禁用探针；仅在甲骨文 ARM 配置指定 Connector ID、机器指纹及受控代理白名单。Server 只配置目标 ID，不接触 OAuth 凭据。源码上传不会更改线上配置、安装版本或启动探针。iOS 尚无用量面板，本次仅同步版本。
