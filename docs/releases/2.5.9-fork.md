# Fork 2.5.9：桌面版本对齐与安卓原生工作台

Android 2.5.9（versionCode 21）替换 2.5.8 的内嵌网页入口。多 AI 选择、模型/推理强度/权限、附件选择、分屏、统一输入及转发对话框均在原生 Compose 界面内运行；每栏复用既有原生聊天、附件、审批、消息队列及即时补充。每个会话独立连接，横向滑动不会停止其他栏的队列。

从新会话页选择已有项目后打开「原生多 AI 工作台」，选择 1–3 个 AI，填写任务并选择附件（最多 10 个，总计不超过 25 MB，防止移动端内存溢出）。统一输入按栏入队，空闲会话先发，忙碌会话等待；原队列支持即时插入。部分栏入队失败时保留原文并只保留失败目标，避免已成功栏重复发送。

每栏可点击「转发」选择设备上的任意可用 AI，也可输入「转发给 AI 名称：审核或继续执行指令」。源任务停止后由服务端交接原始任务、含未提交改动的代码快照、最近约 24000 字符的对话及附件；来源模型不接收这条转发命令。自定义 AI 名称、带空格名称及多行指令均支持，重名时要求完整标识。

历史任务组可以恢复，转发链会保留祖先及后续会话。网络失败重试保留操作标识；投递结果不明确时查看原会话，不创建新任务重放。恢复的原生消息队列仍需确认继续，沿用旧版行为。

复用已部署的 Server/Connector 2.6.0 任务组 API，无接口变更或数据库迁移；工作区需要 Git 仓库，初始基线须干净。Windows 已发布 2.5.9 版本对齐更新，桌面功能沿用 2.5.8；Intel Mac 的 2.5.9 DMG / PKG 尚未发布，受构建平台阻断影响，现有 2.5.8 继续可用。
