## 修复内容

- Claude Code、Codex、DSH 保存会话明确选择的模型、思考强度和权限。旧快照不能覆盖已保存选择；缺失模型确认、切换失败或回执不一致时阻止发送，直到用户明确选择成功。仅修改权限不能解除模型确认限制；没有模型目录能力的 Runtime 不强制选择模型。
- Web、Desktop、Android 根据确认结果即时提示切换结果，区分立即生效与下一轮生效。确认不足时自动查询一次，仍无法确认则提示重新选择。
- 补齐运行时实例的原生历史删除转发；保留共享目录和受保护路径的删除限制，并显示已知清理失败原因。
- Android 多 AI 新建页将配置放入可滚动区域，为输入和发送区域保留空间；一个 Bash 围栏代码块显示为一张卡片，整块复制保留原始空行和缩进。

## Git 权限处理与部署前提

多 AI 创建和转发共用工作区处理逻辑。可读取且确认没有 HEAD、objects、config 的 `.git` 占位目录会被跳过；无法访问的 Git 元数据会返回明确错误，不会根据目录链接数猜测它为空，也不会把真实仓库静默降级为普通对话。

这不等于线上 `.git/HEAD` 权限问题会随升级自动消失。管理员需要以实际 Connector 身份核对工作目录、`.git` 及父目录权限：真实仓库应提供必要的遍历、读取和工作树写入权限；确认无仓库用途的空占位目录才可另行清理或调整权限。不要自动递归放开权限或删除未知 `.git`。本次源码提交不执行上述设备操作。
