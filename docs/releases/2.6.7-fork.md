# Agents Anywhere Fork 2.6.7（2026-11-14）

本版已部署 ARM、instabox1、instabox2 的 Connector 和腾讯云 Fork Server/Web。桌面及移动端源码版本为 2.6.7，但本轮未构建或安装 Windows、Mac、Android、iOS 安装包，也未完成真机验收。

## 修复内容

- Claude Code、Codex、DSH 保存会话明确选择的模型、思考强度和权限。旧快照不能覆盖已保存选择；缺失模型确认、切换失败或回执不一致时阻止发送，直到用户明确选择成功。仅修改权限不能解除模型确认限制；没有模型目录能力的 Runtime 不强制选择模型。
- Web、Desktop、Android 根据确认结果即时提示切换结果，区分立即生效与下一轮生效。确认不足时自动查询一次，仍无法确认则提示重新选择。
- 补齐运行时实例的原生历史删除转发；保留共享目录和受保护路径的删除限制，并显示已知清理失败原因。
- Android 多 AI 新建页将配置放入可滚动区域，为输入和发送区域保留空间；一个 Bash 围栏代码块显示为一张卡片，整块复制保留原始空行和缩进。

## Git 权限处理与部署前提

多 AI 创建和转发共用工作区处理逻辑。可读取且确认没有 HEAD、objects、config 的 `.git` 占位目录会被跳过；无法访问的 Git 元数据会返回明确错误，不会根据目录链接数猜测它为空，也不会把真实仓库静默降级为普通对话。

升级不会自动修改目录权限。ARM 的环境修复已给 Connector 增加实际仓库的必要 ACL，并为需要访问的账号仅信任该具体仓库；原有 AI 用户的权限保留。

工作区根目录的空 `.git` 还用于 Codex 沙箱的只读路径挂载，不能因为它为空就删除。该占位目录已恢复，并允许 Connector 读取和遍历；Codex 普通沙箱已恢复，Claude、DSH 也通过各自系统账号的仓库读取、隔离双工作树创建与补丁转发验证。三个 AI 的私有目录及 SSH 身份仍各自隔离。

其他设备部署前仍需核对目录权限和沙箱配置。不要自动递归放开权限、删除未知 `.git`、使用 `safe.directory=*` 或在占位目录执行 `git init`。

## 配套更新与范围

完整修复需要部署本版 Connector、Server，并重新构建所用的 Web、Desktop 或 Android 客户端。只更新客户端不能修复 Connector 的历史删除或工作区逻辑；只更新 Connector 不会改变 Android 布局。本次没有数据库迁移，不纳入新的用量探针、用量显示或刷新行为修改；现网已经启用的用量热修复原样保留，不回退到源码中的旧实现。
