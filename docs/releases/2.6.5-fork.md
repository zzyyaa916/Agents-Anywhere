# Agents Anywhere Fork 2.6.5

Connector、Server、Web、Windows/Mac Desktop、Android、iOS 与 DSH Bridge 源码统一为 2.6.5。Android versionCode 26，iOS build 15。客户端源码升版不代表 Windows / Android 安装包已构建或安装。

包含前一提交 d70d1fc07 的同名项目子目录、会话专属清理和精简用量界面；见[项目目录说明](../fork/project-directories.md)。Server 与工作设备 Connector 需配套更新，客户端需按本版重新构建。数据库仍使用 v2_59，不增加迁移；探针只在既有甲骨文 ARM 节点启用并保留纯手动策略，其他节点不启用。

升级前复制原环境，在新环境中离线安装已校验 wheel 并核对依赖与导入，再切换服务；失败回滚。运行时代理及助手文件一致时不重启代理，避免中断原生会话。保留登录、配对、项目文件及既有探针设置。

部署范围为腾讯 Fork Server/Web、甲骨文 ARM、instabox-tao 与 instabox-agent；08184dafe 的实际结果见下文。正式桌面 / 移动端签名安装包由使用方构建，iOS 未在本机编译。

## 取消历史任务恢复（独立客户端修改）

Web、Desktop 和 Android 移除“恢复多 AI 任务”列表；明确关闭联立视图时清除当前组合、窗口状态和联立输入状态，独立会话、原生历史、项目文件和后台任务不受影响。Web / Desktop 忽略旧保存的任务组，阻止本地已关闭组的旧链接重新打开，已删除成员的旧组退回选择界面；Android 丢弃旧版恢复选择，但保留仍在打开的视图在屏幕旋转时的状态。

普通会话的转发、新建多 AI 任务及进行中的分支链路保留。任务组后台记录仍供这些链路关联使用，不作破坏性清库；项目删除仍按原有数据库外键清理所属记录。此修改只影响客户端，Connector 无需再次升级。Web 需重新构建部署，Windows / Android 需按新提交重新打包。本段源码修改尚未随 08184dafe 部署。

验证：Web 与 Desktop 联立/转发交互测试各 30 项通过，两端 TypeScript 检查及 Web 协议生成检查通过；Android 单元测试 195 项全部通过，包含关闭视图的账号隔离、旧恢复选择迁移和活动任务的分目标重试。未构建 Windows / Android 安装包，未进行 iOS 编译和真机界面验收。
