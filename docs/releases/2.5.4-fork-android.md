# Android Fork 2.5.4

Android 原生 Kotlin/Compose 客户端，Android 8.0+，独立包名 `com.agentsanywhere.fork`，版本号 2.5.4 / versionCode 15，可与官方版并排安装。Fork APK 使用稳定独立签名，后续更新只选择本 Fork 的 APK，不按 Server 版本提示官方升级。默认自托管 Fork，可选择自己的服务地址；账号继续由管理员创建，不提供公开注册。

配套：既有 Fork Server 2.5.1 无需新增接口或数据库迁移；Claude 被动用量需要工作设备升级 Connector 至 2.5.4。安装手机 APK 不会自动替换服务器、Windows/macOS 或其他机器的 Connector。iOS 不在本期。

## 功能

- 删除：会话和项目菜单新增永久删除；已归档列表同样可删。项目读取完整会话总数（含归档），输入项目名确认，携带 expectedSessionCount 防止并发新增后误删。409 展示运行会话 ID 或要求重新确认数量，403 提示无权删除。成功即移除可见条目；仅清理平台历史和上传附件，不删除工作目录文件。
- 用量：圆形按钮展开双 Runtime 账号缓存，按哈希区分账号，显示剩余比例、窗口、模型范围、重置时间与更新时间。过期保留旧值并标记，不猜 100%；首次无数据等待原生事件。刷新请求现有 Server 门禁，手机不读取厂商凭据，不直连厂商接口。
- 续聊：限额等待提示、恢复时间、重新检查、停止等待；到点重读原会话状态，保留原 session/thread/context。只有用户主动发送才继续，没有到点后台自动重发。
- 补充：运行中发送普通消息先进入输入框上方的本机队列，保留上传附件引用和稳定 clientMessageId。当前回合结束后按 FIFO 发送；原生能力允许时才可点击立即补充。审批、计划审阅、离线、未接管、限额等待不自动派发。停止任务/应用进入后台会暂停队列，重开恢复也暂停；失败或未知结果保留条目，先检查会话再手动重试。

队列只在当前客户端，不跨桌面/手机同步；清除应用数据会丢失草稿；关闭应用不继续执行队列。网络结果未知不能保证恰好一次，使用同一 clientMessageId 并拒绝自动重放。现有 Goal/Plan 命令、审批、文件、终端与原生历史流程继续沿用。

## Claude 数据来源变更

新的 Connector 仅观察正常任务的 SDK RateLimitEvent，不读取 OAuth token、不请求 /api/oauth/usage、不为刷新发送任务。缺少比例或重置时间不猜测数值，不支持的原生版本显示等待/不可用；更换账号不会把旧连接事件记录给新账号。首次原生登录仍由用户完成。详见 [来源修订](../fork/claude-native-usage.md)。

原生事件通常仅在状态变化时产生，闲置时无法提供实时额度。不承诺降低到零封号风险。本期没有实际厂商账号探测和付费任务测试。
