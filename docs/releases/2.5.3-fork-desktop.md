# 2.5.3 分叉桌面版：待发送消息与 Windows 盘符选择

Desktop/renderer/Web 源码版本 2.5.3，配套既有 Connector 2.5.2、Fork Server 2.5.1；无数据库迁移或新接口，原生账号授权不因本次更新迁移或重置。Windows x64、macOS Intel x64 继续使用独立 Fork 安装身份；按用户要求，后续 Mac 仅交付 Intel 安装包，替代此前 universal 包。

## 运行中继续输入

- 任务执行期间，Enter/发送将新内容放到输入框上方「当前客户端待发送消息」，不停止原任务；支持原生 steer 且当前能力可用时，每条消息有「立即补充」按钮。
- 不支持即时补充的 Agent（当前 Claude）保留排队功能，当前任务结束后依次发送。审批、计划审阅、离线、未接管时不自动派发。停止当前任务会暂停队列；错误态不自动重试，能力恢复后可手动发送待发送条目继续原会话。
- 消息与已上传附件引用保存在当前客户端，按服务器/账号/会话区分；其他设备不共享这份队列。重新打开后需点击「继续排队发送」；发送失败或结果未知保留消息，先检查会话再决定是否重试，避免重复执行。
- 「移除」删除尚未发送的本地条目，不能撤回已经送到 Agent 的内容。浏览器本地存储被清除会丢失本地草稿；关闭客户端时不继续派发。

## 项目目录

Windows 项目选择器可从 C:/Users 返回 C:/，再回到盘符列表，选择 D:/ 等其他盘；正反斜杠路径和盘符列表刷新均已覆盖。UNC 共享根不被截成不可访问的服务器路径。
