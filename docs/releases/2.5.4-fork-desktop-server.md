# Fork 2.5.4 — Windows、Intel Mac 与服务器

本次将桌面主程序、renderer、Server/Web 版本统一为 2.5.4，桌面安装包包含已发布 Android 配套的 Connector 2.5.4。原有删除、圆形用量、限额原会话续聊、运行中消息队列和能力驱动的即时补充保留；不新增 wire API 或数据库迁移。

Claude 用量仅接收本 Connector 正常运行任务产生的 SDK 原生限额事件，缓存窗口/比例/重置时间，手机与桌面读取同一 Fork Server 缓存。缺少事件或字段时等待数据，不请求私有 OAuth 接口，不为刷新启动任务。服务器终端独立启动的 Claude 进程不在本次事件捕获范围内。详见 [数据来源](../fork/claude-native-usage.md)。

## 升级与回退

Windows 继续使用既有 Fork appId、名称、回调和数据目录，覆盖升级 Fork；不会覆盖官方应用。Mac 仅构建 Intel x64 DMG，沿用既有 Fork 标识；本次没有 Apple 签名/公证凭据，因此安装包仍为未签名测试版。桌面安装前应等待 Fork 本机任务结束，再退出 Fork；远端任务由其各自 Connector 管理。没有远程控制个人电脑的通道时，需要用户下载安装。

服务器先备份 Fork 数据库、附件、部署配置与已安装包，再更新独立镜像或 Fork 虚拟环境；认证与原生配置留在各自设备，不复制或上传凭据。保持相同 Connector ID 和原生配置目录，保留已登录状态；不接管官方用户/进程。只重启目标 Fork 服务，不重启宿主或官方服务。失败时恢复旧镜像/包与原服务参数；本期无 schema 迁移，无需降级官方数据库。

安装包、逐项验收与实际部署状态在 [本次交付记录](../fork/2.5.4-desktop-server-delivery.md) 中记录。构建通过不等于 Windows/Intel Mac 真机安装、真实额度或原上下文续聊验收通过。
