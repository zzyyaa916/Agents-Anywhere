# 2.4.0 分叉版 P2（未发布）

基于 P1 2.3.0；沿用官方跨端 MINOR 规则，各端版本元数据同步 2.4.0。新增 account-usage/1.0 契约与 `/api/v2/account-usage`（缓存）、`/refresh`（受统一间隔限制）。接口升级需同步 Server、Connector、Web、Desktop；原生移动端无用量 UI。

升级前备份 PostgreSQL 与附件目录，在独立测试环境升级并验证后替换生产。Alembic 升级至 v2_55；回滚时先停新版本 Server 的采集调度，再执行 downgrade v2_54，安装 P1，丢弃的只是用量缓存与采集门禁。不得回滚生产库而不备份。

默认启用集中采集；`AGENT_SERVER_ACCOUNT_USAGE_POLLING=0` 可关闭后台采集，手动刷新仍执行统一门禁。Server 多 worker 与不同用户共享相同 Runtime/账号时共用数据库采集锁。账号归属和 UI 读取仍按用户隔离。Connector 升级前返回不可用，不影响会话。

Codex 使用本机短生命周期 app-server 只读方法；Claude 使用指定 OAuth 用量接口，本机凭据只用于直连 Anthropic。API key / 模型网关、自定义 environment/codexHome 暂显示不可用，防止错误读取默认账号。账号标识采用稳定 UUID/邮箱的 SHA-256；不保存明文邮箱、token、原始错误或原始响应。Claude 非官方接口有变化风险；解析器集中在 Connector。

本地测试通过不代表真实账号比对通过。未访问真实账号用量、未部署、未产出 Windows/macOS 安装包；继续使用 P1 的手动原生打包工作流。详细验收与改动文件见 P2 交付报告。
